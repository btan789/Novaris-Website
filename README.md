# Novaris Website

Static site for the Novaris STEM Racing team, served by GitHub Pages at https://novarisaus.com.

- `*.html`, `members/` – pages
- `css/` – Webflow export stylesheet plus `team-row.css` and `footer-partners.css`
- `js/` – Webflow runtime (`jquery.js`, `webflow.*`) and our own scripts: `hero.js`, `partners.js`, `gallery.js`, `smooth-wheel.js`
- `images/` – photos and partner logos

There is no build step. To preview locally, serve the folder with any static file server.
